# KaleidoFire (万华烟花) 优化历程
> 记录从“光污染”到“电影级高保真”的视觉迭代过程。

## 📅 阶段一：视觉秩序的建立
最初的问题集中在**视觉过曝**和**透视比例失调**。
- **光污染治理**：通过引入 `ACES Filmic Tone Mapping`，我们成功地将 Additive Blending 的爆发力约束在了高动态范围内，解决了死白问题。
- **空间归位**：将相机拉回至 `z=15` 的广角视野，校准了 `ndcX/Y` 到世界空间的映射距离（`dist=12`），确立了物理空间的黄金比例。

## 📅 阶段二：粒子美学的精雕细琢
烟花的美感源于粒子的“细、碎、亮”。
- **晶莹化重构**：将全局粒子缩放从 `280` 大幅降至 `110`，并在 Shader 中实现了 `pow(1.0 - d*2.0, 2.2)` 的非线性 Alpha 衰减。
- **形态拓扑修复**：重点修复了“爱心”形态的缩放坍缩 Bug，并微调了“锦冠”、“垂柳”等 18 种形态的细节参数，确保每种烟花都有独特的性格。

## 📅 阶段三：体验重构与盛典模式
为了提升交互体验，我们将功能进行了极致精简。
- **盛典模式上线**：移除复杂的音乐同步，将自动燃放升级为“盛典模式”。优化了随机分布算法（`0.08 - 0.92`），使烟花呈现出全屏均衡绽放的壮丽感。
- **UI 极简主义**：重构了控制面板，移除所有冗余开关，仅保留核心形态切换与盛典控制。

## 🚀 未来调优指引
- **物理真实感**：可以通过调整 `FireworkPool.ts` 中的 `gravDrop` 公式，实现不同行星引力下的烟花效果。
- **粒子细节**：修改 `BURST_FRAG` 中的 `oval` 计算逻辑，可以实现不同比例的拉伸（Tail）效果。
